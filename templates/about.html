About the Project

Mental Health Crisis Detection is a machine-learning based student depression-risk screening system designed to identify patterns associated with depression risk using academic, lifestyle, financial and mental-health related factors.

🎯 Project Objective

The objective of this project is to develop an early-screening system that uses machine learning to estimate depression risk among students.

The system analyzes multiple student-related factors and provides a probability-based screening result. This can support awareness and encourage students to seek appropriate help when needed.

⚠️ Problem Statement

Students may experience academic pressure, work pressure, financial stress, sleep-related issues, dissatisfaction and other factors that can be associated with depression risk.

Identifying patterns in these factors can help create an early screening mechanism that highlights potential risk for further attention.

📊 Dataset

The project uses the Student Depression Dataset. The original dataset contains 27,901 records covering academic, lifestyle, financial and mental-health related attributes.

⚙️ How the System Works

1

Student Input

The student provides information through the assessment form.

2

Preprocessing

Input values are converted into the format expected by the trained model.

3

ML Prediction

Logistic Regression estimates the probability of depression risk.

4

Risk Category

The probability is mapped to a prototype screening category.

🧹 Data Preprocessing

Before training the machine-learning model, the dataset was cleaned and transformed.

  • The non-predictive id column was removed.
  • Records containing ? in Financial Stress were removed.
  • Yes/No attributes were converted into binary numerical values.
  • Sleep Duration and Dietary Habits were ordinally encoded.
  • Categorical features were one-hot encoded during model training.
  • Numerical features were standardized before classification.

🤖 Machine Learning Model

The project uses Logistic Regression for binary classification.

The model learns relationships between the input features and the target variable Depression.

Instead of producing only a class label, the trained model estimates P(Depression = 1). This probability is then used by the screening system to determine the prototype risk category.

📈 Model Performance

The Logistic Regression model was evaluated on the project's test set using standard classification metrics.

85.58% Accuracy
86.52% Precision
89.28% Recall
87.88% F1 Score

These metrics are from the project's 80/20 stratified test split.

📌 Prototype Risk Categories

The predicted probability is mapped into three prototype screening categories:

Low Risk

0% – 30%

Moderate Risk

Above 30% – 70%

High Risk

Above 70%

These are prototype screening categories for this educational project and are not clinical thresholds.

⚠️ Limitations

  • The system is designed for educational and early-screening purposes.
  • The prediction depends on the information entered by the student.
  • The model's output should not be interpreted as a medical diagnosis.
  • Prototype risk categories should not be treated as clinically validated thresholds.

🛡️ Important Disclaimer

This project is an educational machine-learning prototype for early screening and awareness. It does not diagnose depression or replace a qualified mental-health professional.

If someone is experiencing emotional distress, suicidal thoughts, or concerns about their mental health, they should seek appropriate professional or emergency support.
