HOW IT WORKS

From Student Data to Risk Insight

01

Student Information

Academic, lifestyle, financial and mental-health related information is provided.

02

Machine Learning

The trained model analyzes the provided information and estimates depression probability.

03

Risk Insight

The probability is converted into an interpretable prototype risk category.

Important Notice

This system is intended for educational and early-screening purposes only. A machine-learning prediction must not be considered a medical diagnosis or a substitute for professional mental-health assessment.

Project Highlights

🤖 Machine Learning

Uses Logistic Regression to estimate depression-risk probability from student-related factors.

📊 Data Analysis

Analyzes academic pressure, sleep, financial stress, suicidal thoughts and other factors in the dataset.

⚡ Early Screening

Provides prototype Low, Moderate and High risk categories based on the model's estimated probability.

🌐 Web Application

Provides an interactive Flask-based interface for assessment, prediction and model visualization.
